# ☕ Brew & Bloom Café

A premium café website built with HTML, CSS, and JavaScript — featuring liquid glassmorphism design, real food photography, add-to-cart functionality, and full mobile responsiveness.

## Pages
- **Home** — Hero, stats, featured dishes, customer favourites, values
- **About** — Café story, team, values
- **Menu** — 24 items across Breakfast / Lunch / Drinks / Desserts with tabbed navigation
- **Contact** — Contact form with validation, address, map

## Features
- 🥃 Liquid glassmorphism UI (dark brown + gold + green)
- 🛒 Add-to-cart with sliding drawer, quantity controls, order summary & checkout
- 📱 Fully responsive — mobile-first design with swipe support
- 🎨 Premium animations: parallax hero, scroll reveal, 3D card tilt, animated counters
- 💾 Cart persists across pages via `localStorage`
- ♿ Accessible — semantic HTML, ARIA labels, keyboard navigation, focus management

## Tech Stack
- HTML5, CSS3 (custom properties, glassmorphism, CSS Grid/Flexbox)
- Vanilla JavaScript (ES6+, IntersectionObserver, localStorage)
- Google Fonts — Playfair Display + Inter
- Unsplash for photography

## Run Locally
```bash
npx serve . -p 3000
```
Then open [http://localhost:3000](http://localhost:3000)
